Features

Designed around how scientists actually look at data.

  • 01

    Fast, even on huge files

    Move through volumetric timeseries at full resolution. No proxies, no precomputation, no stalls.

  • 02

    Voxel-perfect rendering

    Physically faithful and MIP volume modes that stay crisp at every zoom level.

  • 03

    Fluid 3D navigation

    Fly or orbit through your data. Move between modes without losing where you are.

  • 04

    2D and 3D, in sync

    Find any voxel from one view to the other. The two views always agree on what you're looking at.

  • 05

    Annotate and crop in place

    Mark regions of interest. Hide what doesn't matter. Save it all alongside the file.

  • 06

    Multi-channel done right

    Composite views, per-channel controls, and presets you can recall.

  • 07

    Reproducible by default

    Sessions and action logs make every step you took recoverable later.

  • 08

    Publication-ready output

    Single frames, sequences, and movies — ready to paste into a paper or talk.

Use cases

Built for real science.

vizi is designed around the data and the workflows scientists actually use — not synthetic benchmarks.

  • Calcium imaging

    Smooth scrubbing through long acquisition timeseries. Per-channel composite display for multi-fluorophore experiments. Built and tested on data from MicroManager-style pipelines.

  • SCAPE microscopy

    FOCO Lab SCAPE compressed-zip files open directly — voxel intensities, channel layout, and anisotropic pixel sizes come from the embedded metadata. T/Z/C dimensions match the file's anatomical axes so Z-scrubbing acts like depth.

  • OME-TIFF, large or small

    Volumetric OME-TIFFs above 10 GB scrub smoothly at full resolution. Plain TIFFs without OME-XML open too — you specify the T×Z split on first open, and vizi remembers it.

  • Annotation & curation

    Named bounding boxes persist per file. Global X/Y/Z crops. Click-to-fly between 2D and 3D. Designed for the inspect-mark-export loop, not just look-and-close.

Under the hood

A modern stack, where it counts.

The fast parts are written in Rust. The interactive parts are written in Python. The rendering is GPU-native through wgpu.

Render

pygfx & wgpu

GPU-native rendering through wgpu, the same modern graphics API that backs Firefox and Servo. Vulkan on Linux, Metal on macOS, DX12 on Windows — same code path everywhere.

UI

PySide6 & pyqtgraph

Native Qt widgets and toolbars on every platform. No web view, no electron shell. The window opens fast and stays responsive while gigabyte files load behind the scenes.

I/O

Rust hot path

The TIFF reader and pyramid builder are written in Rust and exposed to Python through PyO3. The wheel ships with the Rust extension prebuilt — no toolchain required on the install machine.

Distribution

One wheel, three Pythons

Built against Python's abi3 interface, so a single per-platform wheel works on Python 3.11, 3.12, and 3.13. Native installers (AppImage, .exe, .dmg) bundle their own Python.

Workflow

Where vizi fits.

In the middle of every imaging pipeline — between raw acquisition and downstream analysis or publication.

Project status

In private beta. Open-source release planned post v1.0.0.

vizi is in active development at FOCO Lab. Labmates and a handful of external collaborators are the current users; bug reports surface in real-world install paths. The repository and binary releases are private for now — the source will move to a public repo, with open binary downloads, after the v1.0.0 milestone.

Cross-platform: Linux (AppImage), Windows (.exe), macOS Apple Silicon (.dmg). Vulkan / Metal / DX12 backends through wgpu.

About

Built at FOCO Lab.

FOCO Lab studies how biological brains produce real-time behavior — from the 302-neuron C. elegans to tardigrades, cultured human organoids, and in silico networks. vizi began as the lab's internal viewer for SCAPE and calcium-imaging acquisitions, and grew into a general-purpose workbench for anyone working with large volumetric image data.
