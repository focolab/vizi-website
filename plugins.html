Submit a plugin

Email focolabdev@gmail.com with the repository, the version, and the release asset. Each version is audited and accepted separately — acceptance of a new version is a new review. The release must follow the contract on the vizi-plugin-sdk repository.

Access each plugin requests is shown above and declared in its manifest; vizi grants only what the plugin declares.
