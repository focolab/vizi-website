Submit a plugin

A plugin does not need to be on this list to work. Acceptance only adds it here, so vizi can install it for you from inside the app. Anyone can build a plugin with the vizi SDK and install it themselves.

Email focolabdev@gmail.com with the repository, the version, and the release asset. Each version is audited and accepted separately.

A plugin's minimum vizi version only rises across its accepted versions. Access each plugin requests is shown above and declared in its manifest; vizi grants only what the plugin declares.
