Licenses

Open-source components in vizi.

vizi's installers bundle two open-source libraries. Their licenses require that we offer the exact source we build from, so the corresponding source and checksums are published below.

Bundled components

vizi's installers include FFmpeg 9.0.2, used under the GNU Lesser General Public License, version 3 or later (LGPL-3.0-or-later), and libvpx 1.17.0, used under the BSD 3-Clause license. Both are built by the FOCO Lab; the exact configure options used for each build are recorded in the THIRD_PARTY_NOTICES.txt file included with every vizi installer.

Corresponding source

These archives are byte-for-byte the upstream releases vizi builds from. Verify a download against the published checksum with sha256sum.
